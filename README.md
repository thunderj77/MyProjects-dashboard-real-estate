## 📊 Назначение

Платформа позволяет:
- Быстро оценить ключевые метрики рынка
- Отследить динамику цен и объёмов предложения
- Сравнить характеристики разных типов жилья и локаций
- Выявить сезонные и недельные паттерны публикаций

## 🗂️ Структура дашборда

### Вкладка 1 – **Обзор**
- Общее количество объявлений
- Динамика цен за м²
- Средняя площадь, число комнат, площадь кухни
- Фильтры по дате, типу населённого пункта, наличию апартаментов/открытой планировки

### Вкладка 2 – **География**
- Средняя цена по городам
- Количество объявлений по населённым пунктам
- Стоимость квадратного метра в разрезе локаций

### Вкладка 3 – **Параметры**
- Влияние парков и водоёмов на стоимость
- Сравнение апартаментов vs обычных квартир
- Открытая vs закрытая планировка

### Вкладка 4 – **Динамика**
- Количество публикаций по месяцам/годам
- Дни недели с пиком объявлений
- Среднее время экспозиции (дней в продаже)
- Топ-5 городов по скорости продажи

## 🎛️ Основные фильтры

| Фильтр | Описание |
|--------|----------|
| Дата объявления | Выбор периода (рекомендуются полные годы 2015–2018) |
| Тип населённого пункта | Город / не город |
| Апартаменты | Да / Нет |
| Открытая планировка | Да / Нет |
| Гранулярность | Год / Месяц / Неделя / День |

## 📈 Доступные визуализации

- **Линейчатые диаграммы** – цены, количество объявлений, дни продаж
- **Круговые диаграммы** – доля апартаментов, открытой планировки, влияния парков/водоёмов
- **Таблицы** – рейтинг городов по стоимости м²
- **Графики с областями** – тренды цен и объёма во времени

## 🗃️ Источники данных

Дашборд построен на основе объединённых таблиц:

| Таблица | Содержание |
|---------|------------|
| `flats` | Параметры квартир (площадь, комнаты, этаж, балконы и т.д.) |
| `advertisement` | Данные объявлений (дата публикации, цена, дни экспозиции) |
| `city` | Справочник городов |
| `type` | Тип населённого пункта |

> База данных: PostgreSQL 14, хостинг – Yandex Cloud.

## 🧠 Как использовать

1. Выберите период (рекомендованы **полные годы** для корректной сезонности)
2. Примените нужные фильтры (город, цена, площадь, планировка)
3. Кликайте по элементам графиков для детализации
4. Экспортируйте данные или скриншот через меню в правом верхнем углу
